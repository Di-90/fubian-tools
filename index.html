下面每个卡片是一个可直接在浏览器里操作的可视化工具，配合课堂相应章节使用。点开即用，无需安装；手机、平板、电脑都能打开。

动态形变类（映射非线性与区域形变）
T1

复平面运算器

复数加减乘除与共轭的几何演示：拖动 z1、z2，动态观看向量拼接、旋转伸缩与翻折，实时读出模与辐角。

▶ 打开使用
 T2

球极投影 / 复球面

从北极把复平面上的 z 投影到单位球面：z=0 ↔ 南极、|z|=1 ↔ 赤道、z→∞ ↔ 北极，理解无穷远点与复球面。

▶ 打开使用
 T3

映射网格形变器

左右双平面看 w=f(z) 把网格“扭”成什么形状；形变滑杆展示弯曲过程，局部标架直观感受保角性。

▶ 打开使用
 T4

区域与曲线映射

在左右两个平面上，把一条曲线或一块区域经 w=f(z) 映射过去，实时画出变形后的图形并填充区域。内置常见图形库（线段/圆/圆弧/矩形/圆盘/半平面/带形/扇形）与参数方程，可拖控制点或调参数。

▶ 打开使用
路径依赖类（简单闭曲线积分与级数收敛域）
T5

简单闭曲线积分

拖动简单闭曲线（圆 / 椭圆 / 矩形）或奇点，实时对照 ∮f(z)dz 的数值积分与 2πi⋅∑Res，直观感受柯西积分定理、路径无关与留数定理。

▶ 打开使用
 T6

共轭调和等值线

纯理论概念版（不带物理背景）：给解析 f(z) 自动拆出实部 u、虚部 v，画出 u=c（蓝实线）与 v=c（橘虚线）处处正交的等值线族；也可反过来给实部 u(x,y)，先验调和性再由 C-R 反求共轭 v（大纲难点）。可自由输入函数、开 Δu 热图验证调和性。

▶ 打开使用
 T7

泰勒 / 洛朗收敛域

拖动展开中心 z0，看泰勒收敛半径被最近奇点卡住、相邻奇点之间形成不同的洛朗环；选定域后用柯西积分数值求系数，收敛热图（绿收敛 / 红发散）直接铺满所选圆盘 / 圆环，配合测试点与项数 N 感受域内收敛、域外发散。

▶ 打开使用
应用案例
T8

交流电路的相量法

串联 RLC 电路的复数视角，把复数的概念用活：拖 R / L / C / 频率，同看旋转相量图、时域正弦波与阻抗三角形 Z=R+jX。模=电压电流幅值之比、辐角=相位差、复数相加=阻抗串联、乘 j=逆时针转 90°（电感超前 / 电容滞后）；滑到谐振频率看电流最大、电压电流同相。

▶ 打开使用
 T9

调和函数与共轭调和

解析函数 f=u+iv 的实部、虚部都是调和函数，而电势 / 稳态温度 / 速度势在无源区都满足拉普拉斯方程。以物理场景为入口（匀强场 / 直角角流 / 点源 / 偶极子 / 绕圆柱 / 多点源叠加），一键切换静电场 / 温度场 / 理想流体三种身份，看等势线与正交场线、由 u 求 v 的 C-R 推导；可开 Δu 热图验证调和性并对照非物理反例。

▶ 打开使用
时频对应类（积分变换 · 傅里叶）
T10

傅里叶级数合成器

周期波形（方波/锯齿波/三角波/半波整流）如何由正弦、余弦逐项叠加拼出：拖“项数 N”看部分和 SN 逼近目标，下方是各次谐波振幅谱；直观看懂吉布斯现象、连续/跳变波形谱衰减快慢之别。

▶ 打开使用
 T11

频谱与傅里叶变换对

从周期到非周期：周期信号的离散谱线（T10）随 T→∞ 挤密成连续频谱，即傅里叶变换 F(ω)。左时域、右频谱并置，内置矩形/高斯/双边指数/单边指数/冲激/常数/余弦七组常见变换对；可切幅度谱与相位谱，拖参数体会时窄↔频宽与时宽×频宽≈常数。

▶ 打开使用
 T12

卷积演示

卷积 (f∗g)(t) 的“翻转—平移—相乘—求积分”动画：拖平移量看重叠面积如何生成结果曲线；并演示卷积定理——时域卷积等于频域相乘。

▶ 打开使用
 T13

傅里叶变换的性质

把变换性质“看见”：时移 → 相位旋转、频移 → 调制、尺度伸缩 → 时窄频宽、微分 → 乘 jω。左右同看信号与频谱随操作的联动变化。

▶ 打开使用
 T14

卷积定理

把时域卷积 = 变换域相乘"看见"：用两条独立算出的曲线是否重合来验证定理。傅里叶版看频谱 |F⋅G| 与卷积结果的谱重合；拉普拉斯版看 ℒ−1{F(s)G(s)} 与直接卷积重合，并给出 s 域代数式（承接 T12 卷积、通向 T16 解方程）。

▶ 打开使用
时频对应类（积分变换 · 拉普拉斯）
T15

复频率 s 平面与时域响应

在复频率 s=σ+jω 平面上拖动极点，实时看对应时域响应：左半平面 → 衰减、虚轴 → 等幅振荡、右半平面 → 发散；标注收敛域，并说明 σ=0 时与傅里叶变换的关系。

▶ 打开使用
 T16

拉普拉斯解微分方程 / 电路暂态

拉氏变换解常系数微分方程的“变换 → 代数求解 → 逆变换”三步走，以二阶系统（RLC 电路暂态）为例，拖参数看欠阻尼 / 临界阻尼 / 过阻尼三种响应与极点位置的对应。

▶ 打开使用
拓展与名例欣赏（选学 · 非考试内容）
T17兴趣拓展

飞机为什么能飞

复变函数的一次著名应用：一百年前，数学家用你正在学的解析函数、调和函数描述机翼周围的气流，再借一个“把圆捏成机翼”的映射，算清了升力。分幕向导 + 圆↔机翼变形动画，带你一步步看懂，还能手算几个点看圆怎么“压”成机翼。
（核心用到的保角映射属课外拓展，了解即可、不考；真正挂钩大纲的解析 / 调和函数见 T9、留数见 T5。）
