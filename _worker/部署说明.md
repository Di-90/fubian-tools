# 课程小工具网站 · 部署与访问统计说明

这套东西分两半：
- **网站本体**（`index.html` + 各工具 html）→ 放 **GitHub Pages**，学生扫码/点链接访问；
- **访问计数**（`counter-worker.js`）→ 放 **Cloudflare Workers**，负责记 PV/UV 并导出。

计数是「尽力而为」的：即使某次连不上计数服务，工具照常打开，最坏只是少统计一次，不影响使用。

---

## 一、先把网站发到 GitHub Pages

沿用你线性代数那次的做法即可：

1. 在 GitHub 新建一个仓库，例如 `fubian-tools`（Public）。
2. 把这个文件夹里的内容传上去，保持结构：
   ```
   index.html                 ← 课程门户首页
   T1_复平面运算器.html         ← 工具（以后 T2、T3… 一起放这里）
   _worker/                    ← 计数服务代码（不影响网站，可一起传）
   ```
3. 仓库 **Settings → Pages → Build and deployment → Source 选 "Deploy from a branch"**，分支选 `main`、目录 `/ (root)`，保存。
4. 等一两分钟，页面会给出网址，形如：
   ```
   https://你的用户名.github.io/fubian-tools/
   ```
   这就是学生访问的主页。单个工具的网址是它后面接文件名，例如：
   ```
   https://你的用户名.github.io/fubian-tools/T1_复平面运算器.html
   ```
> 域名暂时先用这个免费的 github.io，够用；以后想要短一点的自有域名再说。

## 二、部署计数服务（Cloudflare Workers，全程网页操作，免费）

### 1. 注册并新建 Worker
1. 打开 https://dash.cloudflare.com/ 注册/登录（邮箱即可，免费套餐）。
2. 左侧 **Workers & Pages → Create → Create Worker**，起个名，如 `fubian-counter`，Deploy。
3. 部署后点 **Edit code**，把编辑器里的示例代码**全部删掉**，粘贴 `counter-worker.js` 的全部内容，点 **Deploy**。
4. 部署页会显示这个 Worker 的网址，形如：
   ```
   https://fubian-counter.你的子域.workers.dev
   ```
   **记下它**，下一步要用。

### 2. 建一个 KV（存计数的小仓库）并绑定
1. 左侧 **Workers & Pages → KV → Create a namespace**，名字随意如 `fubian_counts`，创建。
2. 回到你的 Worker → **Settings → Variables and Secrets（或 Bindings）→ 找到 "KV Namespace Bindings" → Add binding**：
   - **Variable name（绑定名）填 `COUNTS`**（必须一字不差，代码里用的就是它）；
   - Namespace 选刚建的 `fubian_counts`；保存。

### 3. 设一个导出口令
1. 同一个 Worker 的 **Settings → Variables and Secrets → Add**：
   - 名称 `ADMIN_KEY`，值填一段只有你知道的口令（如 `hedi-2026-fubian-x7q`），类型选 Secret，保存。
2. 保存后 Worker 会自动重新部署。

## 三、把计数网址回填到网页里（关键一步）

现在需要把每个页面里的占位网址换成你的 Worker 网址。

- 在 `index.html` 和每个工具 html（如 `T1_复平面运算器.html`）里搜索这一行：
  ```js
  var CNT_ENDPOINT = "https://REPLACE-ME.workers.dev";
  ```
- 把 `https://REPLACE-ME.workers.dev` 换成第二步记下的真实网址（**结尾不要带斜杠**），例如：
  ```js
  var CNT_ENDPOINT = "https://fubian-counter.你的子域.workers.dev";
  ```
- 每个工具文件里还有一行 `var TOOL = "T1_复平面运算器";`——**新工具记得改成对应的名字**（这就是统计表里的行名）。首页固定是 `"_home"`，不用改。

改完重新推到 GitHub 即可生效。（未回填时代码会自动跳过计数，不报错。）

## 四、生成学生用的二维码

拿到网址后生成二维码贴到 PPT / 讲义：
- 主页二维码 → 编码 `https://你的用户名.github.io/fubian-tools/`
- 也可给每个工具单独做二维码，直接指向该工具的网址。

生成方式任选：微信「草料二维码」网站、或浏览器搜「免费二维码生成」，把网址粘进去下载 PNG。（无需下载软件。）

## 五、随时查看 / 导出访问量

在你自己的浏览器地址栏打开（把口令换成你设的 `ADMIN_KEY`）：

- **下载 CSV（Excel 直接打开）**：
  ```
  https://fubian-counter.你的子域.workers.dev/stats?key=你的口令
  ```
  会得到一张表：每个工具的「访问次数(PV)」「访问人数(UV)」，最后一行是合计。

- **看 JSON**（想自己再加工时用）：
  ```
  https://fubian-counter.你的子域.workers.dev/stats.json?key=你的口令
  ```

> PV = 一共被打开了多少次；UV = 有多少台不同的设备/浏览器打开过（按浏览器本地标记去重）。两个数都能作为教改「工具触达面」的成效数据。

## 六、两点如实说明

1. **国内可达性是尽力而为**：GitHub Pages 你上次反馈基本顺畅；Cloudflare 计数接口国内多数能通、偶尔慢或不通。计数失败时工具照常用，只是少记一次，对量级数据无碍。若以后要国内绝对稳的计数，可改用腾讯云 CloudBase / 云函数（更稳但配置更重，需要时再弄）。
2. **计数在极高并发下可能少算个位数**（KV 最终一致），一门课的规模完全够用。

## 附：想用命令行（wrangler）部署的话

若你更习惯命令行，可在本 `_worker/` 目录放一个 `wrangler.toml`：

```toml
name = "fubian-counter"
main = "counter-worker.js"
compatibility_date = "2024-01-01"

[[kv_namespaces]]
binding = "COUNTS"
id = "把 KV 的 id 填这里"
```

然后：
```
npm i -g wrangler
wrangler login
wrangler kv namespace create COUNTS      # 建 KV，把返回的 id 填进上面的 toml
wrangler secret put ADMIN_KEY            # 设导出口令
wrangler deploy                          # 部署
```
导出计数也可用：`wrangler kv key list --binding COUNTS`（网页 /stats 更省事）。
