手机、电脑只能每隔一小段时间记一个数（采样）。采得太慢，快的信号就会冒充成慢的信号（混叠）。拖动下面各面板的滑杆，从时域（采样点）和频域（频谱复制）两头看清楚：为什么要求 fs>2fmax，以及车轮为什么会"倒转"。

从生活到数学：采样是怎么回事？

故事。声音、温度、画面都是随时间连续变化的，可存储器只能存有限个数。办法是每隔 Ts 秒记一次当时的值，这叫采样；每秒记多少次，叫采样频率 fs。

CD 音乐：每秒记 44100 次（44.1 kHz）。人耳最高约听到 20 kHz，44.1 kHz 刚好超过它的两倍。
打电话：每秒只记 8000 次（8 kHz），只保留 3.4 kHz 以下的声音，所以电话里的声音"发闷"。
电影/视频：每秒 24～60 帧，相当于对画面"每秒采样 24～60 次"。

采得太慢会怎样？两次记录之间信号已经来回振荡了好几次，记下的点连起来就像一个慢得多的信号——快信号"冒充"慢信号，这叫混叠（aliasing，"冒名顶替"之意）。电影里车轮变慢、静止、甚至倒转（③），声音采样太慢时高音被听成低音（④ 可以亲耳听），都是混叠。

生活说法怎样对上课本符号、采样定理怎样一步步推出来，都在下面三个折叠块里。

  2. 逐项变换。ℱ[δT]=1Ts∑n2πδ(ω−nωs)=ωs∑nδ(ω−nωs)。
  3. 相乘变卷积。Fs(ω)=12πF(ω)*ωs∑nδ(ω−nωs)=1Ts∑nF(ω−nωs)（与 δ(ω−nωs) 卷积 = 平移 nωs，与 f*δ(t−t0)=f(t−t0) 同理）。

采样：每隔固定时间记一次值。采样频率 fs：每秒记几次。奈奎斯特频率 fs/2：采样能"如实表示"的最高频率。混叠：高于 fs/2 的成分被采样后变得和某个低频成分无法区分。低通滤波：只让低于某频率的成分通过。重建：由采样点恢复连续信号。本页横轴用频率 f=ω/2π（单位 Hz），这样 2π 不会到处出现。

③ 电影里的车轮为什么会倒转

摄像机每秒拍 F 帧，就是以 fs=F 采样。车轮每秒转 r 圈、有 N 根一模一样的辐条时，转过 1/N 圈画面就完全一样，所以画面的重复频率是 Nr（次/秒）。按混叠公式折回 [−F/2,F/2]：

fa=Nr−mF∈[−F2,F2],看起来的转速=faN（圈/秒）正号 = 正转，负号 = 倒转，0 = 静止。

真实的手机、录音笔在采样之前都有一个"抗混叠滤波器"，先把高于 fs/2 的声音滤掉，所以打电话时高音是消失（声音发闷），而不是变成怪异的低音。本页故意去掉了这一步，让你听见混叠。

看什么？三个观察要点

① 时域：采样点"认不出"频率。7 Hz 和 3 Hz 的余弦在采样点上一模一样，重建总挑最低的那个。

② 频域：复制品闯进通带。时域的"冒充"＝频域的"复制品闯入"，同一件事两种说法。

③ "大于两倍"里的"大于"很要紧。恰好两倍时，信号可能整个消失。

展开：每条要点在图上怎么看

① 时域：采样点"认不出"频率。在 ① 里选"7 Hz→3 Hz"，黑点同时落在 7 Hz 的蓝线和 3 Hz 的红线上。只看黑点，没有任何办法区分这两个信号；重建（低通滤波）总是挑最低的那个解释，于是 7 Hz 被冒充成 3 Hz。

② 频域：复制品闯进通带。同一个状态下看频谱：原谱线 ±7 跑出了绿色通带，而 7−10=−3 和 −7+10=3 两根复制品闯了进来（红色）。时域的"冒充"＝频域的"复制品闯入"，是同一件事的两种说法。在 ② 里，这就是两个三角形重叠的红色区域。

③ "大于两倍"里的"大于"很要紧。选"恰好两倍"（f=fs/2），再把初相 φ 拖到 90°：每个采样点都恰好落在零点上，信号"整个消失"了。所以采样定理要求 fs>2fmax，不能取等号。车轮"恰在 F/2"时也是这种方向说不清的情形。

使用说明

这是什么：演示"采样"——每隔 Ts 秒记一次信号值——会带来什么：采得够快能完整恢复原信号；采得太慢，高频会冒充成低频（混叠）。最上方的"从生活到数学"面板把生活中的说法与数学公式一一对应（对照表、推导链、术语小词典都在折叠块里，点"展开"看）。各面板的长读数和推导也收在"看数值验证""看推导"里，✓/✗ 判定始终可见。

怎么玩：

  • ① 单个余弦：拖信号频率 f 和采样频率 fs，上图看采样点和红色重建曲线，下图看谱线如何复制、哪根闯进绿色通带。也可以直接点预设按钮。
  • ② 频带：固定带宽 B，把 fs 从 3B 往下拖到 B，看三角形频谱从分开到重叠，重建误差随之变大。
  • ③ 车轮：左边是真实轮子（转得快时只能看到糊影），右边是摄像机每秒 F 帧拍到的画面。拖转速 r 找到"静止""倒转"的位置，再勾"涂红"对比。
  • ④ 声音（进阶，点标题展开）：点"5000 Hz @ 8000"预设，先听"真实声音"，再听"采样后听到的"，后者明显低沉——它就是 3000 Hz。
  • 开关与提示：只影响某一张图的开关在该图卡片的标题栏里（① 时域图的"原信号 / 重建信号 / sinc 分量"，③ 车轮图的"涂红"与播放速度）。改了某个控件，受影响的图会闪一下蓝光；图不在屏幕内时，底部会提示"↓ … 已更新"，点它就跳过去。
  • 手机上：屏幕底部固定条可直接拖采样频率，它跟着你正在看的面板切换：看 ① 时调 ① 的 fs，看 ② 时调 ② 的 fs，看 ③ 时调帧率 F（即 ③ 的采样频率）；条左端的编号标明当前对应哪个面板，与面板里的滑杆同步。

三个观察要点：①采样点无法区分 f 与 |f−mfs|；②时域冒充 ＝ 频域复制品闯入通带；③恰好两倍不够，必须严格大于。

与其它工具：T11（傅里叶级数：冲激串展开成谱线）、T12（频谱：余弦 ↔ 两根冲激，矩形 ↔ Sa）、T15（卷积定理：时域相乘 ↔ 频域卷积）。

说明：重建曲线用 sinc 插值的数值求和（每点取 800～1800 个采样点、加平滑窗截断）计算，在 f<fs/2 时与原信号的最大误差小于振幅的 0.1%。声音用 Web Audio 播放，个别手机需先关闭静音键。
